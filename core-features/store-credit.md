# Store Credit

RewardsPro maintains a complete store credit system with double-entry ledger and audit trail.

## How Store Credit Works

Store credit is:
- Earned through cashback on purchases
- Added manually by merchants
- Used at checkout like gift cards
- Tracked with complete history

## Credit Sources

| Source | Description |
|--------|-------------|
| **Cashback** | Automatically earned on orders |
| **Manual Credit** | Added by merchant |
| **Refund to Credit** | Converted from refunds |
| **Promotional** | Bonus credits from campaigns |
| **Adjustment** | Corrections and fixes |

## Viewing Balances

### Customer List

See balances in the customer list column.

### Customer Detail

View complete breakdown:
- Current balance
- Total earned (lifetime)
- Total redeemed
- Pending credits

## Managing Credit

### Add Credit

1. Go to customer detail
2. Click **Add Credit**
3. Enter amount
4. Select reason
5. Add note (optional)
6. Confirm

### Remove Credit

1. Go to customer detail
2. Click **Remove Credit**
3. Enter amount
4. Enter reason
5. Confirm

### Refund to Store Credit

Convert a refund to store credit:
1. Open customer detail
2. Click **Refund to Store Credit**
3. Select the order
4. Enter amount (full or partial)
5. Confirm

## Transaction History

Every credit change is logged:

| Field | Description |
|-------|-------------|
| Date | When transaction occurred |
| Type | Cashback, manual, refund, etc. |
| Amount | Positive (credit) or negative (debit) |
| Balance | Running balance after transaction |
| Reference | Order number or note |
| Admin | Who made the change |

### Exporting History

1. Open customer detail
2. Go to Store Credit tab
3. Click **Export**
4. Download CSV

## Using Store Credit

### At Checkout

Customers can apply store credit:
1. View balance in widget
2. At checkout, credit is available
3. Apply full or partial amount
4. Remaining paid by card

### Balance Display

Customers see their balance in:
- Customer widget
- Account page
- Checkout (if available)

## Best Practices

### Adding Credit

✅ **Do:**
- Always include a reason
- Use consistent naming
- Notify customer of credit

❌ **Don't:**
- Add without documentation
- Forget to communicate
- Over-credit accounts

### Audit Trail

Keep records clean:
- Use descriptive reasons
- Link to orders when applicable
- Review transactions regularly
