# Customer Management

The Customers page is your command center for managing loyalty program members.

## Customer List

### Viewing Customers

The main list displays:
- Customer name and email
- Current tier (with badge)
- Store credit balance
- Lifetime spending
- Member since date

### Searching

Search customers by:
- Name
- Email address
- Partial matches supported

### Filtering

Filter the list by:
- **Tier**: Show specific tier members
- **Balance**: Has credit / No credit
- **Status**: Active / Inactive

### Sorting

Sort by:
- Name (A-Z, Z-A)
- Balance (High-Low, Low-High)
- Spending (High-Low, Low-High)
- Join Date (Newest, Oldest)

## Customer Details

Click any customer to view their profile:

### Overview Tab
- Contact information
- Current tier and progress
- Store credit balance
- Key statistics

### Orders Tab
- Order history
- Cashback earned per order
- Order status

### Store Credit Tab
- Transaction history
- Add/remove credit
- Refund to credit option

### Activity Tab
- Tier changes
- Credit transactions
- Recent orders

## Syncing Customers

### Initial Sync

First time setup:
1. Click **Sync Customers**
2. Wait for import to complete
3. Review imported customers

### Automatic Sync

Customers are automatically added when they:
- Create an account
- Place their first order

### Manual Refresh

Click **Sync** to update customer data from Shopify.

## Managing Individual Customers

### Change Tier

1. Open customer detail
2. Click **Change Tier**
3. Select new tier
4. Add reason (optional)
5. Save

### Add Store Credit

1. Open customer detail
2. Go to Store Credit tab
3. Click **Add Credit**
4. Enter amount and reason
5. Confirm

### Refund to Credit

1. Open customer detail
2. Go to Store Credit tab
3. Click **Refund to Credit**
4. Select order
5. Enter refund amount
6. Confirm

## Bulk Operations

### Export Customers

1. Apply desired filters
2. Click **Export**
3. Download CSV file

### Bulk Tier Assignment

1. Filter to target customers
2. Select multiple customers
3. Choose **Assign Tier**
4. Select tier and confirm
