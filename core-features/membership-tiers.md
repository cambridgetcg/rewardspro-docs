# Membership Tiers

Tiers are the foundation of your loyalty program. Each tier offers different benefits based on customer spending.

## How Tiers Work

1. **Customers shop** → Spending is tracked
2. **Thresholds reached** → Automatic tier upgrade
3. **Benefits applied** → Higher cashback rate

## Managing Tiers

### Viewing Tiers

Navigate to **Membership Tiers** to see all your tiers with:
- Tier name and color
- Spending threshold
- Cashback rate
- Number of members

### Creating Tiers

Click **Create Tier** and configure:

| Setting | Description |
|---------|-------------|
| Name | Display name shown to customers |
| Minimum Spend | Amount required to reach tier |
| Cashback Rate | Percentage earned (0-100%) |
| Color | Visual identifier (hex code) |
| Description | Benefits summary |

### Editing Tiers

Click any tier to edit. Changes apply to:
- New tier calculations
- Customer widget display
- Future cashback rates

> **Note**: Existing earned cashback is not recalculated.

### Deleting Tiers

Before deleting:
1. Reassign customers to another tier
2. Or merge into existing tier
3. Then delete

## Tier Configuration

### Cashback Rates

Recommended ranges by tier level:

| Level | Rate Range | Example |
|-------|------------|---------|
| Entry | 1-2% | Bronze: 2% |
| Mid | 3-4% | Silver: 3% |
| Upper | 5-6% | Gold: 5% |
| Top | 7-10% | Platinum: 8% |

### Spending Thresholds

Make tiers achievable:

| Tier | Suggested Threshold |
|------|---------------------|
| Entry | $0 (default) |
| Level 2 | $200 - $500 |
| Level 3 | $1,000 - $2,000 |
| Top | $2,500 - $5,000 |

## Evaluation Periods

### Annual Evaluation

- Spending calculated from past 12 months
- Customers can move up or down
- Encourages ongoing purchases

### Lifetime Evaluation

- Total spending since account creation
- Customers only move up
- Rewards long-term loyalty

## Default Tier

Every store needs a default tier:
- Assigned to new customers
- Cannot be deleted
- Usually your entry-level tier

## Best Practices

✅ **Do:**
- Keep 3-4 tiers for simplicity
- Make first upgrade achievable
- Increase rates meaningfully
- Use descriptive tier names

❌ **Don't:**
- Create too many tiers
- Set unachievable thresholds
- Use identical rates
- Forget a default tier
