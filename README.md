<h2 align="center">Rewards Pro User Guide</h2>

<p align="center">RewardsPro is a comprehensive loyalty and rewards<br>platform for Shopify that automatically increases<br>customer lifetime value through tier-based cashback<br>rewards. Turn one-time buyers into repeat customers by<br>rewarding their spending with store credit, while<br>intelligent tier management handles everything<br>automatically.</p>
