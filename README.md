## What is RewardsPro?

RewardsPro is a Shopify app that lets you:

- **Create Membership Tiers** - Bronze, Silver, Gold, Platinum - with increasing cashback rates
- **Reward Purchases** - Automatically calculate and issue cashback on orders
- **Manage Store Credit** - Customers can use their earned credit at checkout
- **Track Performance** - Analytics dashboard shows program effectiveness

## How It Works

```
Customer Places Order → Cashback Calculated → Store Credit Issued → Customer Redeems on Next Order
```

### Example

| Tier | Cashback Rate | $100 Order Earns |
|------|---------------|------------------|
| Bronze | 2% | $2.00 |
| Silver | 5% | $5.00 |
| Gold | 8% | $8.00 |
| Platinum | 10% | $10.00 |
