# Store Settings

Configure RewardsPro to match your store's needs.

## Accessing Settings

Navigate to **Settings** in the RewardsPro sidebar.

## General Settings

### Currency

Set your store's display currency:
- 33 currencies supported
- Affects all balance displays
- Used for tier thresholds

**Supported currencies include:**
USD, EUR, GBP, CAD, AUD, JPY, CHF, and 26 more.

### Timezone

Set for accurate reporting:
- Affects daily/weekly/monthly reports
- Order date grouping
- Analytics dashboards

### Store Name

Display name in customer communications.

## Tier Settings

### Default Tier

Select which tier new customers receive:
- Must have at least one tier
- Usually your entry-level tier
- Cannot be deleted

### Evaluation Period

Choose how spending is calculated:

| Option | Description |
|--------|-------------|
| **Annual** | Rolling 12-month window |
| **Lifetime** | All-time spending |

## Display Settings

### Currency Format

Choose display format:
- **Symbol prefix**: $100.00
- **Symbol suffix**: 100.00 USD
- **Locale-aware**: Based on region

### Number Format

Configure decimal and thousand separators.

## Notification Settings

### Admin Notifications

Receive alerts for:
- [ ] Processing errors
- [ ] High-value transactions
- [ ] Tier upgrades
- [ ] Low engagement alerts

### Customer Notifications

Enable notifications for:
- [ ] Cashback earned
- [ ] Tier upgrade
- [ ] Balance reminders

## Save Changes

Always click **Save** after making changes. Some settings may require a page refresh to take effect.
