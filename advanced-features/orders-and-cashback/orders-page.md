# Orders Page

The Orders page displays all customer orders with their cashback status, allowing you to monitor processing and take action when needed.

## Page Overview

### Order List

Each order displays:

| Column | Description |
|--------|-------------|
| **Order** | Order number (e.g., #1234) |
| **Date** | Order creation date |
| **Customer** | Customer name |
| **Tier** | Customer's tier at order time |
| **Total** | Order total amount |
| **Cashback** | Amount earned or pending |
| **Status** | Processing status |

### Status Indicators

| Status | Badge | Meaning |
|--------|-------|---------|
| ✅ Processed | Green | Cashback awarded |
| ⏳ Pending | Yellow | Awaiting processing |
| ⏸️ Held | Orange | Flagged for review |
| ❌ Failed | Red | Processing error |
| 🔄 Reversed | Gray | Cashback reversed |

## Order Actions

### Process Cashback

For pending orders in manual mode:
1. Review order details
2. Verify customer and amount
3. Click **Process**
4. Confirm cashback award

### Reverse Cashback

If cashback needs to be reversed:
1. Find the processed order
2. Click **Reverse**
3. Enter reason
4. Confirm reversal

### Recalculate

If tier or settings changed:
1. Select order
2. Click **Recalculate**
3. Review new amount
4. Process if different

## Troubleshooting

### Order Not Showing

1. Check date filter
2. Verify order is paid
3. Sync with Shopify
4. Check customer account exists

### Wrong Cashback Amount

1. Review tier at order time
2. Check for excluded products
3. Verify discount handling
4. Recalculate if needed

### Processing Failed

1. Check error message
2. Verify customer has account
3. Check tier assignment
4. Process manually if needed
