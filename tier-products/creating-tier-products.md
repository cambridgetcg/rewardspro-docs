# Creating Tier Products

## Tier Product Coverage

<div data-with-frame="true"><figure><img src="../.gitbook/assets/Screenshot 2025-11-24 at 21.39.50.png" alt=""><figcaption></figcaption></figure></div>

Tier Products Coverage Module can be found in the Membership Tiers Page, which allows you to create, edit and delete tier products.

## Create Tier Product

<div data-with-frame="true"><figure><img src="../.gitbook/assets/Create Tier Products.png" alt=""><figcaption></figcaption></figure></div>

Create a tier product by clicking on the create button in the Tier Products Coverage Module

Choose the Tier, Duration and assign your pricing for the product. These fields can be edited in the future.
