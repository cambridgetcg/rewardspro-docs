# Going Live Checklist

You've set up and tested your loyalty program. Use this final checklist to ensure everything is ready for your customers.

## Pre-Launch Verification

### Core Setup ✓

- [ ] **Tiers Created**: At least 2-3 tiers with logical progression
- [ ] **Default Tier Set**: New customers will be assigned correctly
- [ ] **Thresholds Configured**: Achievable first upgrade, exclusive top tier
- [ ] **Cashback Rates Set**: Sustainable rates for your margins

### Data & Automation ✓

- [ ] **Historical Data Synced**: Existing customers have correct tiers
- [ ] **VIPs Assigned**: Top customers recognized appropriately
- [ ] **Tier Automation Enabled**: Automatic recalculation active
- [ ] **Evaluation Period Set**: Annual or Lifetime (matches your sync)

### Settings ✓

- [ ] **Currency Correct**: Matches your Shopify store currency
- [ ] **Timezone Set**: Reports will use correct local time
- [ ] **Business Metrics Configured**: ROI tracking ready (optional)

### Testing ✓

- [ ] **Test Order Placed**: Cashback calculated correctly
- [ ] **Customer Balance Updated**: Store credit appeared
- [ ] **Tier Upgrade Tested**: Customers promote correctly
- [ ] **Refund Tested**: Cashback reverses properly

---

## Widget & Customer Experience

### Widget Setup (If Using)

- [ ] **App Embed Enabled**: Widget appears on storefront
- [ ] **Position Configured**: Doesn't conflict with other elements
- [ ] **Logged-In View Works**: Shows correct tier and balance
- [ ] **Mobile Tested**: Widget works on mobile devices

### Customer Account

- [ ] **Balance Visible**: Customers can see their store credit
- [ ] **Tier Displayed**: Current tier is shown
- [ ] **Progress Clear**: Path to next tier is visible

## First Week Monitoring

### Daily Checks

| Day | Focus Area |
|-----|------------|
| Day 1 | Order processing, widget display |
| Day 2 | Customer inquiries, tier assignments |
| Day 3 | Cashback calculations, balances |
| Day 4-5 | Overall metrics, any issues |
| Day 6-7 | Prepare first week report |

### What to Watch

- **Order Processing**: Are all paid orders generating cashback?
- **Customer Feedback**: Any confusion about the program?
- **Error Rates**: Any sync or processing failures?
- **Engagement**: Are customers checking their balances?

---

## Common Launch Issues

### Orders Not Processing

**Check:**
1. Order status is "Paid" (not pending)
2. Webhook connection is active
3. Products aren't excluded

### Customers in Wrong Tier

**Check:**
1. Data sync completed successfully
2. Evaluation period matches sync range
3. Manual tier recalculation needed

### Widget Not Showing

**Check:**
1. App embed enabled in theme settings
2. Not blocked by ad blockers
3. Cache cleared on test device
