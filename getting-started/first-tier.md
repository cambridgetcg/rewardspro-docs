# Create Your First Tier

Set up your tier structure to start rewarding customers.

## Planning Your Tiers

Before creating tiers, consider:

| Question | Recommendation |
|----------|----------------|
| How many tiers? | 3-4 tiers is ideal |
| Entry threshold? | Make first upgrade achievable ($200-500) |
| Top tier threshold? | Should feel exclusive but attainable |
| Cashback rates? | Increase meaningfully between tiers |

## Example Tier Structure

| Tier | Threshold | Cashback | Target Audience |
|------|-----------|----------|-----------------|
| Bronze | $0 | 2% | All new customers |
| Silver | $500 | 3% | Regular shoppers |
| Gold | $1,500 | 5% | Loyal customers |
| Platinum | $3,000 | 8% | VIP customers |

## Creating a Tier

### Step 1: Navigate to Membership Tiers

In RewardsPro, click **Membership Tiers** in the sidebar.

### Step 2: Click Create Tier

Click the **Create Tier** button.

### Step 3: Configure Tier Settings

| Field | Description | Example |
|-------|-------------|---------|
| **Name** | Display name | "Gold Member" |
| **Minimum Spend** | Threshold to reach tier | $1,500 |
| **Cashback Rate** | Percentage earned | 5% |
| **Color** | Badge color | #FFD700 (gold) |
| **Description** | Benefits summary | "Earn 5% back on every purchase" |

### Step 4: Save and Activate

Click **Save** to create the tier.

## Setting a Default Tier

One tier must be the default for new customers:

1. Go to **Settings**
2. Find **Default Tier**
3. Select your entry-level tier (usually Bronze)
4. Save changes
