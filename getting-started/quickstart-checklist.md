# Quickstart Checklist

Follow this checklist to get your loyalty program live.

## Setup Phase

### Account & Permissions
- [ ] Install RewardsPro from App Store
- [ ] Grant required permissions
- [ ] Complete setup wizard

### Configure Tiers
- [ ] Create at least 2-3 tiers
- [ ] Set spending thresholds
- [ ] Configure cashback rates
- [ ] Choose evaluation period (annual/lifetime)

### Store Settings
- [ ] Select your currency
- [ ] Set timezone
- [ ] Configure cashback rules

## Launch Phase

### Customer Setup
- [ ] Sync existing customers
- [ ] Assign VIP customers to top tiers manually
- [ ] Test tier assignment

### Widget Activation
- [ ] Enable customer widget
- [ ] Position widget on storefront
- [ ] Test logged-in customer view
- [ ] Test logged-out visitor view

### Testing
- [ ] Place a test order
- [ ] Verify cashback calculation
- [ ] Check customer balance updated
- [ ] Test tier upgrade (if applicable)

## Post-Launch

### Monitor
- [ ] Review analytics dashboard
- [ ] Check for processing errors
- [ ] Monitor customer engagement

### Optimize
- [ ] Adjust tier thresholds if needed
- [ ] Review cashback rates
- [ ] Consider tier products

## You're Live! 🎉

Once you've completed this checklist, your loyalty program is active and customers will start earning rewards.
